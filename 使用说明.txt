Office AI 助手
================================================
一个由 DeepSeek 驱动的轻量 Office 插件，替代海鹦 OfficeAI 助手。
在 Word / Excel / PowerPoint 右侧停靠一个侧边栏，能读全文、能问答、
能按你的确认精准写入文档，能生成 PPT，能抓取全文档图片。
全部在本机运行，只有对话内容会发给你自己配置的模型接口。

一、安装
  1. 双击 install.bat（会弹一次 UAC，需要写注册表）
  2. 完全退出并重开 Word / Excel / PowerPoint
  3. 功能区会出现「AI 助手」选项卡 → 打开文件后侧边栏自动弹出
     （也可手动点「打开侧边栏」）
  4. 点侧边栏右上角齿轮，填入 DeepSeek 的 API Key，保存
  卸载：双击 uninstall.bat（不会删 %LOCALAPPDATA%\OfficeAi，里面有你的 Key）

二、侧边栏三栏
  提问·写作   对话与编辑（默认栏）
  图片        抓取当前文档里的所有内嵌图片

  顶栏右侧：
    ⟳ 刷新      重新读取当前文档内容
    ⚙ 设置      打开设置面板

三、提问模式
  只回答问题，绝不改动文档。
  勾选「带文档内容」后，提问会自动把当前文档全文发给模型。
  还可以点「用选区」锁定一段选区，只针对选中内容提问。

四、写作模式 + 确认导入
  生成内容后先在侧边栏预览，必须点「确认导入」才写进文档。
  写入方式（设置里可改）：
    模拟输入  走宿主自己的"光标处输入"，等于你手打，格式与撤销栈都自然（推荐）
    VBA      生成 VBA 代码注入执行；若宿主没开
              「信任对 VBA 工程对象模型的访问」，会自动退回对象模型并把代码给你看

  精准定位：
    选中定位  在文档里选中一段文字/一个表格单元格 → 点「用选区」锁定
              → 写作模式生成的内容只改写这个选区
    查找替换  点底部「查找替换」，输入查找/替换文本，全文替换
  表格支持：Word 的表格会通过 Content.Text 全文提取（用 \x07 分隔），
            COM 选区可定位到具体单元格（RowIndex / ColumnIndex）。

五、自动读取
  侧边栏打开时自动读取当前文档全文。
  设置面板里可以控制：
    · 是否自动读取（默认开启）
    · 自动刷新间隔（分钟，默认 0 = 不定时刷新）
    顶栏的 ⟳ 刷新按钮可以随时手动重读。

六、生成 PPT
  点底部「生成 PPT」（仅 PowerPoint 宿主可见），按格式写大纲：
      @title 演示文稿标题
      @subtitle 副标题
      @theme  tech-cyan

      # 第一页标题
      - 要点一
        - 子要点（前面空两格）
  可选配色：tech-cyan / business-blue / forest-green / warm-amber
  「用当前文档内容起草大纲」一键生成骨架。
  生成后自动打开（默认存桌面）。生成引擎是 python-pptx，完全本地。

七、图片抓取
  点侧边栏顶部「图片」标签切换到图片页。
  点「抓取文档图片」提取当前文档里的所有内嵌图片。
  每张图片显示：
    · 缩略图预览（不依赖原始文件）
    · 文件名和尺寸
  右键缩略图可以：
    · 用默认程序打开
    · 复制文件路径（即提取后的真实文件路径）
    · 另存为…（保存到任意位置）
    · 在资源管理器中显示
  点「批量导出…」可把所有图片一次性复制到指定文件夹。

  提取后的图片保存在：
  %LOCALAPPDATA%\OfficeAi\imgcache\<文档名>_<hash>\orig\<序号>.<扩展名>
  这些就是"真实文件"，可以复制、另存、用其他程序打开。

八、ima 资料库（需要凭据）
  ima 有 openapi 接口（区别于 WorkBuddy 用 MCP 通道的那个），支持：
    · 搜索知识库
    · 在知识库内搜索内容
    · 获取原文 URL
  需要你从 https://ima.qq.com/agent-interface 领取 client_id 和 api_key，
  在设置面板填入后即可在侧边栏搜索 ima 资料库并把结果插入到对话。
  凭据没配置时 ima 面板的搜索会提示"还没配置 Client ID / API Key"。

九、故障排查
  · 功能区没有「AI 助手」
    确认完全退出并重开 Office
    文件 → 选项 → 加载项 → 管理选「COM 加载项」→ 勾选 OfficeAi.Connect
  · 侧边栏显示"WebView2 初始化失败"
    确认 WebView2Loader.dll 在 Program Files\OfficeAi 根目录
  · 图片抓取失败"请先保存"
    文档未保存到磁盘，先 Ctrl+S 保存再重试
  · ima 搜索报错
    检查设置里的 imaClientId / imaApiKey 是否已填
